# Bank Transactions Analyzer

Приложение для анализа банковских операций из Excel-файла. Проект выполнен в рамках курсовой работы и включает в себя генерацию JSON-данных для веб-страниц, аналитические сервисы и формирование отчетов.

## 🚀 Функциональность

Проект разделен на логические модули в папке `src/`:

- **`views.py`**: Генерация JSON для главной страницы (приветствие в зависимости от времени суток, топ-5 транзакций за месяц, актуальные курсы валют через API ЦБ РФ, цены на акции).
- **`services.py`**: Бизнес-логика для аналитики:
  - `cashback_categories`: Анализ выгодности категорий повышенного кешбэка.
  - `investment_bank`: Сервис «Инвесткопилка» (расчет суммы, которую можно отложить путем округления трат).
  - `simple_search`: Поиск транзакций по описанию или категории.
- **`reports.py`**: Формирование отчетов (например, средние траты в рабочий и выходной день за последние 3 месяца). Включает декоратор `save_report` для автоматического сохранения результата в JSON-файл.
- **`utils.py`**: Утилита для безопасного чтения исходного Excel-файла.
- **`main.py`**: Точка входа в программу, объединяющая все модули.
